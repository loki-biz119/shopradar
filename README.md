ShopRadar
한국 이커머스 셀러를 위한 유튜브 쇼핑 쇼츠 트렌드 분석 플랫폼

서비스 소개
ShopRadar는 미국, 한국, 일본, 태국, 인도네시아 등 5개국 유튜브 쇼핑 쇼츠에서 급상승하는 제품을 분석하여, 한국 온라인 셀러가 트렌드를 선점할 수 있도록 데이터를 제공합니다.

개인정보처리방침
본 서비스는 YouTube Data API v3를 통해 공개된 영상 메타데이터(제목, 조회수, 채널명, 게시일 등)를 수집합니다.

개인 사용자 데이터를 수집하지 않습니다
YouTube 사용자 계정 정보를 저장하지 않습니다
수집하는 모든 데이터는 공개된 유튜브 영상 메타데이터입니다
수집된 데이터는 제품 트렌드 분석 목적으로만 사용됩니다
YouTube API 서비스 이용약관을 준수합니다
